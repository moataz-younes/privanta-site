# Privanta Website - Run Scripts

## Available Scripts

### Development Mode (Recommended for development)
- **run-dev.bat**: Starts development server with hot reload
- Access at: `http://localhost:8080`
- Auto-refreshes when you make changes

### Production Mode
- **run-site.bat** (or **run-prod.bat**): Builds and serves production version
- Access at: `http://localhost:4173`
- Optimized for performance

## How to Run

1. Double-click the desired `.bat` file
2. Wait for the server to start
3. Open your browser and go to the provided URL
4. Press `Ctrl+C` in the command window to stop the server

## Notes
- Make sure Node.js and npm are installed
- The development server shows changes immediately
- The production server serves optimized, built files
